Política de Segurança


Mulher Amparada


A segurança do Mulher Amparada é uma prioridade. Como o projeto pode lidar com informações e recursos relacionados à segurança pessoal, vulnerabilidades devem ser tratadas com responsabilidade.


Versões suportadas


As vulnerabilidades serão analisadas principalmente na versão mais recente do aplicativo e nas versões atualmente mantidas pelo projeto.

Como reportar uma vulnerabilidade


Se você encontrar uma possível vulnerabilidade de segurança, não abra uma Issue pública com detalhes técnicos da falha.


Envie um relatório privado aos responsáveis pelo projeto contendo, se possível:




Descrição da vulnerabilidade;


Versão afetada;


Passos necessários para reproduzir o problema;


Impacto potencial;


Evidências, quando forem necessárias para demonstrar o problema;


Uma possível sugestão de correção, caso exista.




O objetivo é permitir que a vulnerabilidade seja analisada e corrigida antes que seus detalhes sejam divulgados publicamente.


Divulgação responsável


Pedimos que vulnerabilidades de segurança não sejam divulgadas publicamente antes que o projeto tenha a oportunidade de analisá-las e, quando possível, corrigi-las.


Após a correção, os responsáveis pelo projeto poderão publicar informações sobre a vulnerabilidade, sua correção e a versão afetada, preservando informações que possam colocar usuários em risco.


O que não deve ser enviado


Não envie informações pessoais, senhas, chaves privadas, tokens de acesso ou outros dados confidenciais durante o relatório.


Caso seja necessário demonstrar uma vulnerabilidade, utilize apenas dados de teste e evite acessar ou expor dados de outras pessoas.


Escopo


Esta política se aplica ao código, aos recursos e às funcionalidades do projeto Mulher Amparada disponibilizados neste repositório.


Problemas exclusivamente relacionados a serviços de terceiros devem ser comunicados aos respectivos responsáveis, quando apropriado.


Compromisso com a segurança


Agradecemos a todos que contribuírem para tornar o Mulher Amparada mais seguro.


Relatos responsáveis de vulnerabilidades ajudam o projeto a identificar problemas, melhorar suas proteções e oferecer uma experiência mais segura aos usuários.
