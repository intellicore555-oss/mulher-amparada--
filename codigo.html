Tecnologias utilizadas

Conheça as principais tecnologias utilizadas no desenvolvimento e na estrutura do aplicativo.

Smali ›

Linguagem usada no nível baixo de aplicativos Android. É o código que aparece após descompilar APKs e permite manipulação direta da lógica interna do aplicativo.

Kotlin ›

Uma das principais linguagens utilizadas no desenvolvimento Android. Possui uma sintaxe moderna, recursos de segurança e integração com o ecossistema Android.

Java ›

Linguagem tradicionalmente utilizada no desenvolvimento de aplicativos Android, especialmente em projetos que utilizam APIs e bibliotecas do ecossistema Java.

HTML, CSS e JavaScript ›

Utilizados para criar páginas internas, interfaces web, componentes visuais e possíveis telas híbridas dentro do aplicativo.

XML ›

Utilizado na estruturação de layouts Android, permitindo definir elementos como telas, botões, listas e outros componentes da interface.

SVG ›

Formato de imagens vetoriais utilizado para ícones e elementos gráficos. Mantém a qualidade visual em diferentes tamanhos sem perder nitidez.
