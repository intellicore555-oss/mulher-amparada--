🔐 Sistema Cripto (Segurança do App) = Antigo LocalStorage!: 
Este sistema salva dados de forma segura usando criptografia nativa do Android. Quando você salva um dado no app, ele não fica em texto normal no celular. Ele é automaticamente criptografado antes de ser armazenado. Isso significa que mesmo acessando os arquivos do dispositivo, os dados aparecem como códigos ilegíveis. AES-256 (criptografia forte), Android Keystore (chave protegida pelo sistema) e EncryptedSharedPreferences garantem a segurança. salvar(chave, valor) guarda o dado criptografado, carregar(chave) recupera o valor original, remover(chave) apaga um dado específico e limparTudo() remove todos os dados. Os dados ficam protegidos por uma chave segura do Android e não podem ser lidos diretamente.

    Considerações finais:
    Eu penso que, quando o Android Studio ou o GitHub Actions apresenta um erro, uma IA poderia navegar por todo o projeto, identificar o problema e realizar uma correção automática (auto fix).
    Os áudios gravados pelo gravador de voz também são criptografados utilizando a classe Cripto.
    Os recursos de proteção por barulho, chacoalhar o celular e escurecer a tela podem ser ativados e desativados pelo usuário.
    Todas as Activities dos três aplicativos utilizam a flag FLAG_SECURE
    No elemento applicationdo AndroidManifest.xml dos três aplicativos, allowBackup="false" está configurado.
    O aplicativo possui um navegador interno. A navegação para o Google é feita diretamente pelo código usando window.location.replace(), sem disponibilizar o endereço como um link na interface. O aplicativo também não implementa um sistema próprio de registro de histórico de navegação.
